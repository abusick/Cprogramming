# 실습과제 1. C 프로그래밍 기초 및 포인터 개념 이해


### 1. 16MB 메모리의 주소의 범위를 구하시오.
- **답변:** **`0x00000000` ~ `0x00FFFFFF`**
- **해설:** 
  - $1\text{MB} = 2^{20}\text{ bytes} = 1,048,576\text{ bytes}$ 입니다.
  - $16\text{MB} = 16 \times 2^{20} = 2^4 \times 2^{20} = 2^{24}\text{ bytes}$ 가 됩니다.
  - $2^{24}$개의 주소를 표현하기 위해서는 **24비트(Bit)**가 필요하며, 이를 16진수로 표현하면 6자리(`0x000000` ~ `0xFFFFFF`)가 필요합니다.
  - 일반적으로 32비트나 64비트 시스템 주소 체계의 형식에 맞춰 8자리 표기로 나타내면 `0x00000000`부터 `0x00FFFFFF`까지가 주소 범위가 됩니다.

---

### 2. 변수의 주소를 설명하시오.
- **답변:** 변수의 주소란 **해당 변수의 값이 컴퓨터의 메인 메모리(RAM) 상에서 실제로 저장되어 있는 물리적/논리적 위치(시작 번지)**를 의미합니다.
- **특징:**
  - 프로그램 실행 시 운영체제가 메모리 공간을 할당하며, 주소 연산자(`&`)를 사용해 특정 변수의 시작 주소 값을 알아낼 수 있습니다.

---

### 3. 변수의 주소의 자료형은 무엇인가?
- **답변:** **포인터형 (Pointer Type)** 입니다.
- **상세 설명:**
  - 주소 자체가 독립된 고유의 자료형을 가집니다. 가리키는 대상(변수)의 자료형 뒤에 `*`를 붙여서 표현합니다.
  - 예를 들어 `int`형 변수의 주소는 `int*` 형이 되고, `char`형 변수의 주소는 `char*` 형이 됩니다.

---

### 4. 포인터란 무엇인가?
- **답변:** 포인터는 **메모리의 주소 값을 저장하는 특별한 변수**입니다.
- **핵심 역할:**
  - 일반 변수가 '데이터(정수, 실수 등)'를 직접 저장한다면, 포인터 변수는 다른 데이터나 변수가 위치한 '메모리 주소'를 가리킵니다.
  - 포인터에 저장된 주소를 통해 주소지에 위치한 실제 데이터에 직접 접근하거나 조작(`*` 역참조 연산자 사용)할 수 있습니다.

---

### 5. 포인터의 자료형은 무엇인가?
- **답변:** **포인터가 가리키는 대상의 데이터 타입에 따라 결정되는 데이터 타입(예: `int*`, `char*`, `double*` 등)**입니다.
- **중요 개념:**
  - 포인터 변수 자체의 **크기**는 시스템 체계(32비트 환경에서는 4바이트, 64비트 환경에서는 8바이트)에 따라 항상 일정합니다.
  - 하지만 포인터의 **자료형**은 해당 주소로 가서 '몇 바이트를 읽어와야 하는지', '어떤 방식으로 해석해야 하는지'를 결정하므로 명확히 구분되어야 합니다.

---

### 6. 변수의 주소를 int형 변수에 저장하면 어떻게 되는가?
- **답변:** 시스템 환경에 따라 **데이터 손실(Truncation)이나 잘못된 주소 접근으로 인한 프로그램 오류**가 발생할 수 있습니다.
- **원인 분석:**
  - **32비트 시스템:** 포인터(주소)의 크기가 4바이트이고 `int`형의 크기도 4바이트이므로, 주소 값이 잘 저장되고 정상 작동하는 것처럼 보일 수 있습니다. (컴파일러에 따라 경고 발생)
  - **64비트 시스템:** 포인터(주소)의 크기는 8바이트이지만 `int`형은 여전히 4바이트입니다. 따라서 8바이트짜리 주소 값을 4바이트 공간에 강제로 넣으면 **앞쪽 4바이트의 데이터가 잘려 나가는 데이터 손실**이 발생하여 완전히 엉뚱한 메모리 주소를 가리키게 됩니다.
- **결론:** 올바른 주소 저장을 위해서는 항상 포인터 변수를 사용해야 하며, 굳이 정수형에 저장해야 한다면 시스템 환경에 맞춰 크기가 변하는 `uintptr_t`와 같은 특수 자료형을 사용해야 안전합니다.

# 실습과제 2. 포인터 선언문(`double * pt;`)의 이해

double * pt;
```

---

### 1. 다음에서 pt가 가리키는 데이터의 자료형은 무엇인가?
- **답변:** **`double`** 형입니다.
- **설명:** 포인터 변수 `pt`가 가리키는 메모리 주소로 이동했을 때, 그곳에 저장되어 있는 데이터의 타입은 8바이트 크기의 배정도 부동소수점(실수) 자료형인 `double`입니다.

---

### 2. 다음에서 pt에 저장될 주소의 자료형은 무엇인가?
- **답변:** **`double *`** 형입니다.
- **설명:** C 언어에서 '주소 자체의 자료형'은 가리키는 대상의 자료형 뒤에 `*`를 붙인 형태입니다. 따라서 `pt`에 저장되는 값(주소 값)의 자료형은 `double`형 변수의 주소를 의미하는 `double *` 타입이 됩니다.

---

### 3. 다음에서 pt의 자료형은 무엇인가?
- **답변:** **`double *`** (double 포인터) 형입니다.
- **설명:** 변수 `pt` 자체의 데이터 타입(자료형) 역시 `double`형 변수의 메모리 주소를 저장하는 변수이므로 `double *` 형으로 정의됩니다.

---

### 4. 다음 처럼 포인터를 선언할 때 double의 의미를 설명하라.
- **답변:** `pt`가 가리키는 **메모리 시작 주소로부터 '8바이트' 크기만큼의 공간을 읽어 들여 '실수(double)' 형태로 해석하겠다는 의미**입니다.
- **상세 설명:** 
  - 컴퓨터 메모리의 주소는 모두 동일한 형태를 가집니다. 
  - 하지만 앞에 붙는 `double`이라는 키워드는 이 포인터를 통해 메모리에 접근(`*pt` 역참조)할 때, **몇 바이트를 읽어야 하는지(크기)**와 **이를 정수로 볼 것인지 실수로 볼 것인지(해석 방식)**를 컴파일러에게 알려주는 중요한 역할을 합니다.

---

### 5. 포인터 변수 pt가 메모리에 할당될 때 메모리 크기는?
- **답변:** **32비트(x86) 환경에서는 `4바이트`, 64비트(x64) 환경에서는 `8바이트`**입니다.
- **핵심 포인트:**
  - 많은 학생들이 앞에 `double`이 붙어 있어서 포인터 변수 `pt` 자체의 크기가 8바이트라고 오해하기 쉽습니다.
  - 하지만 포인터 변수는 데이터가 아니라 **'메모리 주소'를 저장하는 변수**이므로, 가리키는 자료형(`double`, `char`, `int` 등)과 관계없이 **현재 시스템의 주소 버스 크기(32비트냐 64비트냐)에 따라서만 크기가 결정**됩니다.
# 실습과제 3. 주소 연산자(`&`)와 메모리 할당의 이해

```c
char ch = 'A';
int in = 10;
double db = 3.4;

```

---

### 실습과제3 아래의 변수가 우측 그림처럼 메모리가 할당될 때 다음 표의 빈칸을 채우시오. 

| 수식 | 결과값 | 결과값의 자료형 |
| --- | --- | --- |
| **`&ch`** | **`100`** | **`char *`** |
| **`&in`** | **`101`** | **`int *`** |
| **`&db`** | **`105`** | **`double *`** |

---

### 1. `&ch` 수식의 해설

* **답변:** **결과값: `100` / 자료형: `char ***`
* **설명:**
* `char` 타입 변수 `ch`는 1바이트를 차지하며 메모리 주소 `100`에 할당되어 있습니다.
* 주소 연산자 `&`는 변수가 시작하는 첫 번째 바이트의 주소를 반환하므로 결과값은 **100**이 됩니다.
* `char`형 변수의 주소이므로 자료형은 `char *`**가 됩니다.



---

### 2. `&in` 수식의 해설

* **답변:** **결과값: `101` / 자료형: `int ***`
* **설명:**
* `int` 타입 변수 `in`은 4바이트를 차지하며 메모리 주소 `101`부터 `104`까지 할당되어 있습니다.
* 시작 주소를 나타내므로 결과값은 **101**이 됩니다.
* `int`형 변수의 주소이므로 자료형은 `int *`**가 됩니다.



---

### 3. `&db` 수식의 해설

* **답변:** **결과값: `105` / 자료형: `double ***`
* **설명:**
* `double` 타입 변수 `db`는 8바이트를 차지하며 메모리 주소 `105`부터 `112`까지 할당되어 있습니다.
* 시작 주소를 나타내므로 결과값은 **105**가 됩니다.
* `double`형 변수의 주소이므로 자료형은 `double *`**가 됩니다.



---

# 실습과제 4. 주소 연산자(`&`)를 이용한 변수의 메모리 주소 출력

```c
char a = 'A';
int b = 36;
double c = 3.141592;

```

---

### 1. 작성 코드

```c
#include <stdio.h>

int main(void) {
    char a = 'A';
    int b = 36;
    double c = 3.141592;

    printf("char형 변수 a의 주소 : %p\n", (void *)&a);
    printf("int형 변수 b의 주소 : %p\n", (void *)&b);
    printf("double형 변수 c의 주소 : %p\n", (void *)&c);

    return 0;
}

```

---

### 2. 실행 결과 예시 (16진수 출력)

```text
char형 변수 a의 주소 : 0x7ff7bfeff47f
int형 변수 b의 주소 : 0x7ff7bfeff478
double형 변수 c의 주소 : 0x7ff7bfeff470

```

> **참고:** 실행 환경(32비트/64비트) 및 컴파일 시점에 따라 출력되는 실제 주소 값(`xxxxxx`)은 매번 달라집니다.

실습과제 4. 주소 연산자(&)를 이용한 변수의 메모리 주소 출력
C
char a = 'A';
int b = 36;
double c = 3.141592;
1. 작성 코드
C
#include <stdio.h>

int main(void) {
    char a = 'A';
    int b = 36;
    double c = 3.141592;

    printf("char형 변수 a의 주소 : %p\n", (void *)&a);
    printf("int형 변수 b의 주소 : %p\n", (void *)&b);
    printf("double형 변수 c의 주소 : %p\n", (void *)&c);

    return 0;
}
2. 실행 결과 예시 (16진수 출력)
Plaintext
char형 변수 a의 주소 : 0x7ff7bfeff47f
int형 변수 b의 주소 : 0x7ff7bfeff478
double형 변수 c의 주소 : 0x7ff7bfeff470
참고: 실행 환경(32비트/64비트) 및 컴파일 시점에 따라 출력되는 실제 주소 값(xxxxxx)은 매번 달라집니다.

3. 코드 상세 설명
& (주소 연산자): 변수 이름 앞에 &를 붙이면 해당 변수가 할당된 메모리의 시작 주소를 가져옵니다.

%p 서식 지정자: 포인터 및 메모리 주소를 16진수 형태(0x...)로 출력할 때 사용하는 printf 전용 서식 지정자입니다.

(void *) 형변환: C 언어 표준 규격상 %p 서식 지정자로 주소를 출력할 때는 포인터 타입을 (void *)로 캐스팅(형변환)하여 전달하는 것이 안전하고 정석적인 방법입니다.
